# Face recognition is no longer optional: PIN check-in was removed, so face
# verification is the only way to record attendance. These packages are now in
# requirements.txt and are installed by default - you do not need this file.

# try to compile from source (zlib headers / PyO3 3.13 ceiling). Every package
# below has a prebuilt wheel on every supported interpreter.
#
# Install into the SAME interpreter that runs the API, e.g. on Windows:
#     .\.venv\Scripts\python.exe -m pip install -r requirements-face.txt
#     .\.venv\Scripts\python.exe scripts\download_models.py
