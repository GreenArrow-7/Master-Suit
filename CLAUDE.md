# YOUHAN ONE — start here

Read `changes/README.md` first. It points to `changes/PROJECT.md` (the current
state: modules, rules, where code lives, how to test and release) and indexes
every change since 5 Oct 2026, newest first. Open code only for what the task
touches.

When you finish a change, add its entry to `changes/` in the same PR (the format
is in `changes/README.md`) and correct `changes/PROJECT.md` if the change makes
it wrong. A change without its entry is not finished.
