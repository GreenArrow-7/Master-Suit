# Teams can be created, with a manager and members

**17 Oct 2026** · feature · Admin, scope (audit M1-11, M18-14)

- TEAM scope already read `UserTeam`, but nothing could create a team, so team-scoped roles fell back to "me and my reports".
- Admin → Teams (every workspace, `users:VIEW`; editing needs `users:MANAGE_USERS`): create a team with a name, manager and members; edit or delete it.
- `GET/POST /api/v1/teams`, `PATCH/DELETE /api/v1/teams/{id}`. Members must be people in the workspace; the manager is a member, flagged as such. Membership takes effect at each person's next sign-in.
- Test: `tests/permission/teams.spec.ts` — a team created through the API makes its manager see the member at TEAM scope; editing replaces members; a viewer cannot create.
