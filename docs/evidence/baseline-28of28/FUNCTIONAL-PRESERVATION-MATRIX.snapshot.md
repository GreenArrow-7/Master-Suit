# Functional preservation matrix

Date: 2026-08-03

This is the controlling inventory for the unification work. The untouched source
applications at `../HRMS` and `../Sales Lead Flow` are the functional source of
truth. A copied file, menu item, read-only table, or placeholder is not considered
a completed migration.

Status applies to the requested customer experience under
`/{workspaceSlug}/...` using the shared identity, workspace and subscription. The
only permitted values are **Preserved and working**, **Migrated and working**,
**Temporarily proxied and working**, **Not yet migrated**, and **Blocked**.

## Baseline summary

- LeadFlow comparison: 171 original source/test/schema files; 148 unchanged in
  `apps/web`, 21 intentionally changed, and 2 missing. The original feature pages
  still exist at compatibility URLs, but most slugged Sales routes bypass them
  with reduced tables. They are therefore not marked complete.
- HRMS comparison: all 108 original `app`, `tests` and `web` files exist in
  `apps/hrms`; 71 are byte-identical, while the meaningful source differences are
  in auth/security/bootstrap and three security pages. The service is not part of
  the current customer runtime, so copied code is not marked complete.
- Current vertical slice: owner workspace creation, shared administrator login,
  department creation, employee creation and basic lead creation use one tenant ID
  and passed the existing integration scenario. This slice does not prove the
  complete HRMS or LeadFlow workflows below.
